RichTextBuilder

class RichTextBuilder(source)

Builds a RichText from nested formatting nodes.

val text = richText {
    +"Hello "
    bold {
        +"big "
        italic("world")
    }
    url("https://example.com", "docs")
}
Content copied to clipboard

Every formatting function has three forms: with a RichText, with a plain String and with a nested builder block. Metadata (url, user, ...) always comes before the content.
